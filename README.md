# EchoTalk

Aplicación accesible para comunicación entre una persona sorda y otra que puede escuchar.

## Cómo ejecutar

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

En macOS también puedes usar:

```sh
./run_echo_talk.sh
```

## Compartir en GitHub

1. Crea un repositorio vacío en GitHub.
2. Agrega el remoto:
   ```sh
   git remote add origin https://github.com/USUARIO/REPO.git
   git push -u origin main
   ```
